# Swiftma — installeurs

Swiftma est l'outil de design d'interface piloté par l'IA, du design jusqu'au code, qui tourne entièrement sur ta machine.

**Télécharger** : [dernière version](https://github.com/FranckALPHA/swiftma-releases/releases/latest)

| Système | Fichier |
|---|---|
| Windows | `.msi` ou `-setup.exe` |
| macOS (Apple Silicon) | `aarch64.dmg` |
| macOS (Intel) | `x64.dmg` |
| Linux | `.AppImage` (mises à jour automatiques), `.deb` ou `.rpm` |

L'application démarre avec un essai gratuit de 14 jours, puis demande une clé de licence. Les mises à jour
s'installent depuis l'application.
